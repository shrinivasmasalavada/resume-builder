# resume-builder
This repository helps users build a professional resume using a standard format. It includes templates and guidelines for students and developers.
Create a professional, ATS-friendly resume based on the following details.

Instructions:
- Keep the resume clean, modern, and limited to 1 page
- Use strong action verbs (Developed, Designed, Implemented, Built)
- Focus more on projects and skills rather than marks
- Format should be easy to read with proper headings
- Avoid unnecessary words and keep it concise
